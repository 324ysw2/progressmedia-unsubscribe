# Progressmedia unsubscribe page

Static unsubscribe-request page for Progressmedia Yoo Shin Wooc automated email.

- GitHub Pages URL: `https://324ysw2.github.io/progressmedia-unsubscribe/`
- Submission notifications: `324ysw2@naver.com`
- Form delivery: FormSubmit

The first form submission triggers a FormSubmit activation email. Submissions are delivered after the recipient confirms that activation message.
